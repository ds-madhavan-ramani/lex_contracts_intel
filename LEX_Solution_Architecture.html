Companion to the LEX Delivery Plan · assumes a dedicated LEXDB database and LEX_COMPUTE_POOL compute pool, following the same pattern as FRANK's MEDSGOV / STREAMLIT_COMPUTE_POOL_OCMS_GOVERNANCE — neither created yet for LEX · MTMWH02 as the temporary build warehouse · Azure Private Link connectivity between the MTM Network (including its SharePoint / Microsoft 365 tenant) and Snowflake · cross-region inference to AWS AU for Cortex AI functions · access under named individual logins via the LEX_USERS role, pending confirmation of a dedicated service account for the ingestion path.
